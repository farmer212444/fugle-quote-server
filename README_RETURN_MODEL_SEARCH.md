# V8.10.5：報酬導向選參

目標為相同持有期間內、扣成本後相對0050的平均對數超額報酬。原有EPS／PE估值提供特徵，新增投資報酬選參層。以下都是預先固定、待驗的起始假設，沒有宣稱最佳參數或已打敗0050。

|模型組|起始特徵權重|
|---|---|
|估值|預估Base價差100%|
|成長|最近月營收年增率減累計營收年增率50%；累計毛利率年變動50%|
|動能|前63日至前21日的含股利／分割動能100%|
|品質|同一期營業現金流／營收50%；累計毛利率年變動50%|
|綜合|上述五項各20%|

|參數|候選值|
|---|---|
|持股檔數|10、20、30、50；原始每檔權重1／檔數|
|持有交易日|21、63、126，含進場日，分開選參|
|20日成交額中位數下限|新台幣1,200萬、3,000萬元|
|產業上限|25%、40%|

合計240組、每個持有期80組。特徵做同一訊號可用母體的百分位排名，加權後選股，同分固定依市場與代碼排序。產業上限留下現金；可用公司數或必要資料不足的候選不能變成零報酬樣本。重大治理擋關仍排除，原有13項品質義務及30%／35%認證門檻維持；此處研究組合不自動核發A+。

參數及規格先登錄雜湊。改方法、來源模型或成本另立實驗，所有舊試驗繼續計入比較校正。每組當期名單先寫不可覆寫壓縮快照，真正寫入後的時間才是訊號；當日重跑沿用原名單，不回填8月1日。

依官方0050交易日曆，在訊號後下一實際開盤進場，第N個交易日收盤出場，不以平日猜假日。每個測試訊號只用之前12–36個不重疊且已驗證期間訓練，並保留5個日曆日隔離。首次驗證時間也須早於隔離界線，不能把事後取得的舊日期資料當成當時已知。當期贏家不選當期參數；選中參數當期缺件明列拒收，完整虧損仍保留。

訓練依平均 `log(1+模型淨報酬)−log(1+0050淨報酬)` 選參，單期每日淨資產最大回撤超過30%則訓練排除。較不差的訓練贏家仍可能沒有正超額報酬。1,000萬元參考資金、5%成交參與率上限及30%回撤上限都是研究假設。

足夠證據需60個不重疊測試期間、至少兩種事前定義市況、全部試驗數校正後信賴下限、回撤及成本壓測。新選參競賽重抽樣至少20,000次且不少於40倍全部試驗數；其他既有實驗沿用自己的預註冊統計規格，解析度不足時繼續待驗，不放寬校正。市況以訊號前63日官方加權報酬指數、正／負3%區分上漲／下跌／盤整；缺來源不能算多市況覆蓋。統計使用配對區塊重抽樣與Bonferroni校正，沒有宣稱計算PBO。

每支股票與0050均須提供官方原始位元組、可重解析OHLC、全期間公司行動覆蓋及從開盤起涵蓋的成交審閱。不接受手填報酬、不漏掉虧損股；零成交、未知權利事件、停牌或可成交性未核對者明列待補。股利留現金、分割改股數，每日以淨清算資產計回撤。固定成本假設為買賣各0.1425%、每筆最低20元；股票／ETF賣出稅假設0.3%／0.1%；單邊滑價0.1%加半邊價差0.05%。壓測非稅成本加倍。碎股、費率與可成交模型是研究假設，沒有實盤委託。

此處比較相同區間的獨立組合，沒有納入區間外0050買入持有報酬，不能冒充連續買入持有CAGR。

政策位於 `tw-market-data/config/return_model_search_v1.json`，報告為 `rankings/latest_return_model_search.json` 與 `.md`。登錄及不可覆寫快照位於 `experiments/return_model_search_v1/registrations/`、`{experiment_id}/cohorts/{holding_sessions}/`。

到期來源組合放在 `experiments/return_model_search_v1/inputs/{cohort_id}.json`，綁定 `cohort_sha256`，包含 `stock_legs` 與 `benchmark_leg`。每個leg沿用具雜湊的 `bars`、`actions`、`quote_originals`、`execution_review`、`corporate_action_review` 規格，審閱範圍須完整涵蓋持有窗；不代填審閱人。結果於 `{experiment_id}/outcomes/` 保存首次實際驗證時間，修訂會拒收並要求審查。動能另讀 `evidence/v880/momentum_reviews/{code}.json`，使用64個官方交易日與完整公司行動審閱，缺件留空。

沿用既有研究與行情排程。舊版封存股票即使退出今日排行仍持續蒐集，0050亦按封存起始日補檔；蒐集不等於報酬或可成交已驗證。歷史財報PIT、當時上市下市母體及全期間公司行動仍須補齊，不以今日資料回填歷史。長持有期前瞻驗證需要更長時間，沒有承諾近期即可完成績效認證。
