每次 GitHub 日常研究排程先跑 V8.8.2 估值，再跑 V8.8.3 的13門檻調度，最後跑 `scripts/v884_evidence_probe.py` 產出 `v884_evidence_progress.json` 及 `.md`。本探針針對前50檔實際讀取最近價格檔、逐檔財報鏡像及現有CB法律條件摘要。研究母體仍是1,997檔，前50名以當次排名動態更新。

## 可查核與不可推論的內容

- 檢查 **8季損益及現金流鏡像是否逐期存在**。八季鏡像不等同已審驗完整原始財報、查核意見、附註、管理承諾或揭露精確時間。
- 對封存 `tw-market-data/prices/YYYY-MM-DD.json` 做日期、公司身份、唯一性及最新manifest SHA256核對，取官方原檔記錄的單日成交金額 `turnover_ntd`，**不**使用收盤價×成交股數冒充真實成交額。每檔按5／20／60交易日分別計數，未足N日即為NULL；不將缺資料填成0；排除晚於估值參考日的資料；歷史檔不冒稱獨立官方原始認證。
- 有20日完整成交值，才可計算成交值中位數與假設持倉500萬元、成交參與率20%的「理想化」出場天數。不包含委託簿價差、交易衝擊、漲跌停或停牌，所以 **不能自動宣稱tradability PASS**。
- 已知CB檔案計算已保留舊有的日期、流通餘額、轉換匯率處理；本探針列出尚未確認法律條款，不推導沒有CB就代表完全無稀釋。
- 管理層承諾、會計師範圍、特殊產業營運橋接、精確公告PIT與歷史實際回測，獨立列入人工／原始資料待驗清單。
