# V8.10.6 大成鋼 vs 望隼 vs 飛捷：2027毛利率回歸、費用與現金流壓力複核

研究截點：**2026-10-24**，價格截至**2026-10-22**。本文件內容是**研究假設壓力測試**，不是可成交目標價、財報/個股未來實績驗證或正式A+。

## 1. 兩個不同的模型錯誤來源

不能把全年2027 EPS×PE的潛在報酬率等同可賺報酬：
- **大成鋼2027(代號)**：若利用2026年第二季30.49%毛利率推算全年2027，必須防止美國高鋼價、關稅/價差擴大、庫存評價及鋁材擴廠等循環因子被誤當常態，尤其2025Q2毛利只有24.35%，2025上半年約23.52%。
- **望隼4771/飛捷6206**：2026Q2毛利分別約43.46%與45.4%，對照2025Q2約40.77%、43.9%；即使毛利率回到去年同期，按既有2027 Base營收、費用、PE的機械橋接，**相對股價正報酬模型仍存在，但絕不是利潤保證**。兩家公司應收與存貨、設備投資/資金占用需要另外審視。

## 3. 2027年的關鍵壓力算術

持2027 Base營收、費用、股數、稅/業外、PE不變，只將全年2027假設毛利率替換成**該公司歷史2025Q2單季毛利率**。EPS機械變動係數取原V8.10.5「latest GM flat」敏感度，程式逐項驗證是否與既有Base相符：

|公司|2027 Base GM|原Base EPS|原Base PE|原Base漲幅|用2025Q2 GM取代後EPS約|漲幅約|再把PE砍20%|
|---|---:|---:|---:|---:|---:|---:|---:|
|2027 大成鋼|28.86%|6.87|10.88倍|+47.65%|5.19|+11.49%|-10.80%|
|4771 望隼|41.81%|18.62|15.54倍|+40.11%|17.95|+35.12%|+8.10%|
|6206 飛捷|45.07%|11.57|15.53倍|+40.93%|11.08|+34.97%|+7.98%|

**回到歷史2025Q2並不是對2027年事實的預測**，未來規模、訂單結構、原料、費用及股數可能全都變。且雙重壓力下三檔未必跌相同幅度，不能拿此表直接推估最大回撤或機率。

若只要符合Base價格相對現價至少+30%，以本次既有PE與固定其他假設反推2027年毛利率門檻：約**大成鋼26.66%、望隼39.70%、飛捷42.93%**。並不代表實際應買價或A+完整13門檻。

## 4. 獲利品質/營運資金壓力不可忽略

資料為2026Q2和2025Q2資產負債表二手重刊；成本壓力不直接當負面結論。

- **大成鋼**：2026Q2存貨589.68億元，年增約11.6%、較Q1約降3.6%；應收帳款125.92億元，年增約33%；固定資產479.16億元，年增約39%。上半年標準化營業現金流約**+124.81億元**，有助於排除「僅虛報獲利」式武斷解讀，但毛利是否能跨循環維持仍待證實。資產負債表資料：https://pchome.megatime.com.tw/stock/sto2/sid2027.html
- **望隼**：2026Q2應收帳款10.65億元，較去年6.71億元增加**約58.6%**，**比第二季營收年增37.1%還快**；存貨約3.84億元，年增32.5%；固定資產47.15億元，年增約49.8%。上半年標準化營業現金流**+6.76億元**，仍要確認收現期間、設備投資及匯率。資料：https://stock.pchome.com.tw/stock/sto2/ock0/sid4771.html
- **飛捷**：2026Q2存貨15.10億元，2025Q2僅7.67億元，**接近翻倍**；應收帳款由12.06億元升至16.17億元，約+34%。2026Q2單季OCF轉正約0.999億元，**上半年累計仍為-0.976億元**，必須檢查備料、新訂單、收款及是否有呆滯。飛捷原始公司簡報數字：https://www.flytech.com.tw/investor.php?act=news_view&id=191

應收增加超過收入增幅可能是營運資金風險，但並不證明呆帳、營收灌水或舞弊；對公司客戶條款和交付期比較後再作判斷。

## 5. 研究排序（不等同買進排序）

- **望隼**：營收和毛利本業證據較連貫，歷史毛利率回歸後模型仍約+35%，但應收/擴廠快，需審閱收款天數、設備稼動率及借款公司債條款。
- **飛捷**：EPS模型假設2027≈11.57，比2026上半年EPS5.93機械年化11.86略低，沒有極端EPS成長假設，但現金流/存貨是實質待驗風險。
- **大成鋼**：2026本業/OCF強，循環利潤及估值倍數回落可能吞掉原來+47.6%模型漲幅，需更保守的毛利率分布和鋼鋁價趨勢評估。
