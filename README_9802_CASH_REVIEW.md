# 鈺齊原件現金流與營運資金核對

V8.10.8 重新解析既存公司原件，將 2026H1 營運現金流、帳齡、存貨成本與備抵、期初期末現金橋，以及借款額度與 CB 賣回條款接入主模型和每日研究流程。未修改 EPS、PE、情境價或授予品質認證。

原件與核對時間列在 `tw-market-data/evidence/v880/working_capital_watch/9802.json`。每次載入重新檢查原件 SHA256、公司／單位／財務期、日期與 MOPS 鏡像，再解析指定欄位。營運現金流每項非現金調整及營運資金變動均重新相加，兩期現金流總額和現金餘額亦交叉核對。2025H1 比較數與另一份 2025Q2 原件相互確認。

應收帳款帳齡、備抵與淨額，以及存貨原料／在製品／製成品／在途存貨的成本、備抵與淨額均驗算。資產負債表增減與現金流量表變動仍有未分配差額，保留原值，不強制調平或直接當成匯率。週轉天數為平均淨餘額除以 H1 營收／銷貨成本，再乘實際 H1 天數的代理值；不是逐筆收付款或進貨天數。

現金與未動用銀行額度均保留 2026/6/30 日期。額度不列入現金，也未宣稱目前各子公司、幣別、擔保與契約條件下都能動用。CB 壓測僅以具日期的在外面額乘原件 101.0025% 賣回條款，不預測實際申請比例或交割日；六月底現金扣除此假設，未納入其後收付款、配息與其他負債，因此不能視為即時償付能力或實際資金缺口。

現金原件核對依現金流期別附於主模型。鈺齊採用 Q3 損益自結時，Q2 現金核對仍可見；若後來取得 Q3 現金流，則不沿用 H1 核對。原件缺損、數字／來源不符或未來的核對不產生可用收據。錯誤隔離到該發行人，品質門檻維持待核，既有 FAIL 不會被覆蓋。
