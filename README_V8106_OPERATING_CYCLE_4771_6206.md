## 核心發現：應收帳款年增率≠收帳天數一定惡化

|---|---:|---:|---:|---:|---:|

| 望隼平均售貨天數 |51.43|55.45|51.46|+0.03|−3.99|
| 望隼淨營業週期 (DSO+DIO−DPO) |85.87|96.83|89.65|**+3.78**|**−7.18**|
| **望隼公司簡報轉錄版本**平均收帳天數 |72天|81天|80天|**+8**|**−1**|
| 望隼簡報存貨周轉天數 |53|56|53|0|−3|

| 飛捷平均銷貨天數 |80天|117天|114天|**+34**|−3|

**不同望隼來源的絕對收帳天數不能混算！** 公司法說轉錄與財務比率網站因周轉期間定義、四捨五入或計算方法不同，76.69與80天不能視為同一數值。本次研究先分方法做年差及季差，只有兩種方法共同指出的方向才建立保守判斷：望隼Q2同比收帳較慢、同比營業週期變長；但Q2較Q1已改善。

## 與實際營收、銷貨成本、應收／存貨增幅交叉核對

2025Q2 / 2026Q2單季營業收入與營業成本（NTD千元）：
- **4771望隼**：營收872,361→1,196,065，年增37.11%；銷貨成本516,683→676,206，年增30.88%。應收期末餘額671.35→1,064.78百萬元，約**+58.6%**，年增比營收快；存貨289.95→384.24百萬元，約+32.5%，與COGS增速近似。Q2單季收現改善不能排除全年應收、海外客戶、匯率和帳齡風險。
- **6206飛捷**：營收1,360,861→1,881,598，約**+38.27%**；成本763,949→1,027,619，約+34.51%；應收1,206→1,617百萬元，約**+34.1%**，**低於營收年增**，配合收帳天數79→68天，現有數據不支持「收款效率已惡化」的論述。相反地，存貨767→1,510百萬元，約**+96.9%**，遠高於成本的成長，存貨平均銷售天數80→114天；**主要現金風險在存貨**。

上半年標準化營業現金流：望隼**+6.76億元**；飛捷**−0.976億元**（2026Q2單季轉正+0.999億元），仍須核實存貨庫齡、客戶訂單覆蓋率和未支付固定資產成本。

**不能根據帳款天數增加就認定收入灌水，也不能依庫存增加就推斷已經發生呆滯減損。** 必須調閱公司原始財報附註、應收帳齡表及庫存評價／報廢政策。已保存之資料仍是公開財報重刊、發行人新聞稿及法說簡報轉錄，未冒充原始公司PDF的SHA-256認證。

## 目前研究決策

- 望隼：毛利率回到2025Q2的模擬2027 Base漲幅仍約+35.12%；**續列研究**，優先核對應收天數同比增加及新廠PP&E年增約49.8%，即使上半年現金流為正也不認定全部風險解除。
- 飛捷：模擬2027毛利率回到2025Q2仍約+34.97%；**優先查存貨週轉與現金轉換**。因應收天數同比改善，過去只看應收金額+34.1%推論為收款品質下滑是不精確的。
