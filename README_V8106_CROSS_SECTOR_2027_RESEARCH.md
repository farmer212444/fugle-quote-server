### 優先複核、不是可重押名單

1. **2027 大成鋼**：近年鋼價/美國銷售變動大；2026/09月營收年增41.07%、2026Q2毛利率約30.5%，但若2027原料成本、庫存評價或產業價格逆轉，Base 2027 EPS 6.87和合理PE都可能失準。優先核對北美出貨價量、存貨成本、營業現金流及常態EPS。
2. **4771 望隼**：2026Q2毛利率約43.5%、單季EPS約4.73，上半年EPS8.4；有營運改善證據。需檢查新品矽水膠、兩岸產能、客戶集中、真實現金流與合理PE。
3. **6206 飛捷**：2026Q2 EPS3.42，上半年EPS5.93，Q2 GM約45.4%；本業績效值得複核；但上半年**累積營業現金流仍為負**，Q2單季雖轉正也不能證明應收、存貨與庫存資金占用已完全改善。2027 EPS/PE同減20%，模型Base上漲空間變成-9.80%。完整現金流與出場流動性仍需驗證。
4. **3130 一零四**：需重新開啟資安/治理風險。公司2026/10/06發布重大訊息：約12萬筆履歷資料遭未經授權讀取，後續影響評估中。原模型數值排序沒有這項風險的查核分類，本研究新增 `CYBERSECURITY_PERSONAL_DATA_INCIDENT_IMPACT_OPEN`，將3130自「財務警訊較少」降為「資安治理需複核」。**沒有預設實際訴訟損失或裁罰、未臆測公司責任。**
5. **6143 振曜、8383 千附**：表面漲幅分別+73.5%、+66.7%，但振曜最近單月營收年減約26.9%、上半年營業現金流負；千附近期單季毛利率下降約3.68個百分點，2027Base毛利率較最近單季高3個百分點以上，會計師子公司核閱範圍待查，不可僅用估價最高重押。
