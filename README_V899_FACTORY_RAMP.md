# V8.9.9｜新廠爬坡 vs. 結構性毛利衰退

## 目的與核心原則

毛利率本身不能識別成本的因果。新廠固定折舊／良率／人力訓練造成的暫時性負擔，不等於永久競爭力下降；另一方面，售價下降、品牌組合與原料或工資上漲可能持續。建廠現金資本支出不會直接全部列入當季銷貨成本。

採兩層稽核：

1. 第一層：從交易所標準化2025與2026年Q1/Q2合併損益表，**扣掉Q1累計值形成Q2單季**，比較毛利率與營業利益率；這只能顯示財報變化，不自動歸因。
2. 第二層：只有取得原始公開來源、發表時間、原始檔案SHA256、合併帳務對帳、同範圍同產品單位／存貨成本轉列、固定與變動COGS時，才用單位經濟與利用率作一致性判斷。**這仍不是因果證明，更不等於估值升級。**

### 會計分解公式

毛利率 = 1 − 變動製造成本／營收 − 固定製造成本／營收。

毛利率變化 = −（變動成本／營收變化）−（固定成本／營收變化）。

變動製造成本負擔率可受ASP、產品組合、原料、工資、外匯影響；固定成本比率可受產能利用、庫存成本結轉、折舊及成本分攤變動影響。因此就算公式完全對得上，也不可直接判定是哪個因子主導。條件訊號「固定成本吸收改善一致」採毛利提升至少0.5pp、固定成本／營收下降至少0.5pp、產能利用率增加至少5pp、變動成本／營收沒有惡化超過0.5pp；**這是待回測的研究閾值，並非經驗證的預測機率**。

其他研究分類包括固定成本爬坡稀釋一致、價格／單位變動成本壓力一致、混合驅動與新廠稀釋被其他優勢抵銷。這些分類只辨識會計/營運資料的一致性，不能保證會回升或永遠不會回升。

## 9802鈺齊-KY：目前原公司資料

2026/7/23原公司Q2自結公告：單季營收約52.585億元、毛利率13.94%，比2025Q2低4.55pp、比2026Q1低1.91pp。

公司明列關稅、原料價格、連續調薪及越南／印尼新廠學習曲線、折舊；新設廠2025H2試量產，2026Q2新廠產能占比上升。但未揭露可逐廠、逐品牌產品組合與合併帳務對上的完整產能利用率、鞋雙ASP、單位材料人工、良率、固定成本／存貨成本轉列。

官方新聞稿：https://www.fulgentsun.com/img/News_Release/FY2026%202Q%20financial%20results%20EN.pdf

**不能把4.55pp的下滑全部視為可回復的新廠成本。** 原研究中17%、18%、19%毛利率仍僅是條件式2027估值敏感度，不自動改成Base。

## 原始資料與驗證門檻

新增的企業別原件橋接需提供：

- 兩個年度同季度、同產品與合併範圍，包含合併營收／毛利、原材料、直接人工、其他變動與固定製造銷貨成本，以及銷量、良品產量、產能、良率和產成品庫存數量變動。
- 原公司出版網址、獨立驗證發表時間、核對日期、封存的原始檔案SHA256與檔案路徑；不可使用範例值或新聞轉述充當正式原件。
- 必須逐期和交易所財報數字及原始銷貨成本對帳；沒有足夠資料應保持「原因未核實」，不能變成PASS。

紀錄存放於 tw-market-data/evidence/v880/factory_ramp/（每個代碼一份JSON），原始文件存於該目錄下originals/；未取得原件時不要建立自稱已認證的文件。
