## 原先33元合理價的主要問題

此前以2027營收105億元、12%毛利率、6%營業費用率、業外-0.15億元、20%稅率、約1.664億股、PE11倍得出近33元。然而2026H1已實現營業費用率約7.05%，2026Q2單季約7.90%；2026上半年業外淨支出約0.397億元（其中財務成本約0.666億元）。

因此原版對2027費用及業外負擔的估計缺乏已驗證依據，**不能維持33元作預設基準**。

### 2027估值公式

2027營業利益（億元）＝收入×（毛利率－營業費用率）。
2027淨利（億元）＝（營業利益＋業外淨額）×（1－有效稅率）。
2027 EPS＝淨利（元）÷普通股分母；合理價＝2027 EPS×情境PE。

## 兩項不應犯的會計錯誤

1. 2026H1營業現金流為-114,454千元，為**上半年累積**，不是Q2單季。缺少可核對之不動產廠房設備現金支付金額時，不得以「營業現金流＋全部投資活動現金流」直接標準化為OCF－CapEx自由現金流。
2. 2026Q2研發費用67,550千元，較2025Q2之4,831千元明顯增加。沒有原始附註支持下，不得自行將其視為一次性費用加回獲利。2027費用率仍應對實際費用做壓力測試。
