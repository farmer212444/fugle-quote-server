# 全市場內部人市場買進掃描：自2026年1月起算 V2.1

此為逐步回填資料的研究流程，不代表全市場已完成掃描；先前28家是樣本，不是正式前28名。

## 官方來源與計算口徑

1. 上市及上櫃公司母體、已發行股數：證交所 SIIS 的 IRB110 月報（sii/otc），自2026年1月至最新已申報月份（例如2026/01～2026/09），跨入2027年不得重置；最新月兩市場均成功取得才計算。
2. 內部人真正市場買賣：公開資訊觀測站 MOPS query6_1 事後申報表的「集中市場買進」與「集中市場賣出」。贈與、庫藏股、設解質、員工股、非市場轉讓及事前轉讓通知不列入市場買進。
3. 公司總買進占股本比＝已驗證的自2026年起各已申報月份市場買進股數除以最新已發行股數；淨買進占股本比＝買進減賣出再除以已發行股數。零與未取得資料嚴格區分。
4. 公司只要在自2026年起任何已驗證月份出現市場買進，即加入**暫時追蹤名單**；若未核對自2026年起所有應申報月份，必須明列已核對月份與缺漏；同名不同交易數值、持股橋接不符、原件雜湊驗證失敗，均屬待查。以文字姓名／帳戶類型做初步去重，仍非經正式歸戶認證。
5. 申報原件依回應 SHA256 壓縮保存並記錄首次取得時間；重新下載歷史月報不等於證明該資料於歷史投資時點已可用，不作正式PIT回測、A+或Exit訊號。

## 使用方式

工作流程 .github/workflows/tw_marketwide_insider.yml 每天台灣時間09:30和21:30嘗試增量補抓。每次最多160個公司－月份申報，至少間隔2秒。單次失敗不會刪除舊原件；新的成功收據下次不必重抓。官方站台若封鎖查詢，仍可能無法完成全部資料。

離線測試：python -m unittest discover -s tests -p test_insider_marketwide.py -v

執行：python scripts/insider_marketwide.py --max-details 160 --gap 2

輸出：tw-market-data/rankings/insider_marketwide_latest.json 及同名 .md。報告將列出2026年起已買進的觀察樣本（即使只核到1個月），按照已觀察買進量／股本比例暫時排列，並標示已核對月份及待補月份。未全市場掃描前**不可稱為正式全市場排名，也不可稱為全年累計總買進**。

## 尚待驗證

- MOPS 端點可用性、較早月份是否仍能查詢、欄位是否變動及 GitHub runner 是否受流量限制。
- 每個月新上市公司的上市時點，特殊股別、持有人帳戶實名的唯一性。
- 所有上市櫃公司的逐月覆蓋率及獨立的身份歸戶人工覆核。

來源：證交所 IRB110 https://siis.twse.com.tw/ ，公開資訊觀測站 https://mops.twse.com.tw/ ，上市櫃發行股數 https://openapi.twse.com.tw/ 。

## 2026-10-26 原件解析修復（已建立變更提案，需CI驗證）

- 掃描起始日固定為 **2026-01**，未來月份逐月增加；不採用2006年起點，也不在2027年重置。
- 修正 `query6_1` 申報資料的「私募股數增加／減少」（第10／15欄）持股勾稽；第8／13欄才是集中市場買進／賣出，私募、質押、贈與不計入。
- 「配偶及未成年子女」可能只有關係而沒有姓名，以申報列中的最近具名內部人做保守關聯；不能確認身分時繼續標為待查。
- 同一自然人或法人可能同時是董事、經理人、法人代表、大股東，姓名與完整持股紀錄相同時去重，數值衝突仍須人工驗證。
- 對既有失敗回應先進行原始gzip/SHA256離線重新解析；只有驗證通過才改列成功，否則繼續等待重新抓取。
- 新增2026/09已失敗官方原件的離線回歸測試，以及跨年2027不歸零的測試。

**注意：本流程先修復資料取得與研究可追溯性，不宣稱全市場名次已完成，也不自動將未查月份當作0買進。**
