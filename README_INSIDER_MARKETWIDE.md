# 全市場今年內部人市場買進掃描 V2

此為逐步回填資料的研究流程，不代表全市場已完成掃描；先前28家是樣本，不是正式前28名。

## 官方來源與計算口徑

1. 上市及上櫃公司母體、已發行股數：證交所 SIIS 的 IRB110 月報（sii/otc），本年度自1月到最新已申報月份（例如2026/01～2026/09）；最新月兩市場均成功取得才計算。
2. 內部人真正市場買賣：公開資訊觀測站 MOPS query6_1 事後申報表的「集中市場買進」與「集中市場賣出」。贈與、庫藏股、設解質、員工股、非市場轉讓及事前轉讓通知不列入市場買進。
3. 公司總買進占股本比＝已驗證的本年度各月份市場買進股數除以最新已發行股數；淨買進占股本比＝買進減賣出再除以已發行股數。零與未取得資料嚴格區分。
4. 公司只要在本年度任何已驗證月份出現市場買進，即加入**暫時追蹤名單**；若未核對所有今年月份，必須明列已核對月份與缺漏；同名不同交易數值、持股橋接不符、原件雜湊驗證失敗，均屬待查。以文字姓名／帳戶類型做初步去重，仍非經正式歸戶認證。
5. 申報原件依回應 SHA256 壓縮保存並記錄首次取得時間；重新下載歷史月報不等於證明該資料於歷史投資時點已可用，不作正式PIT回測、A+或Exit訊號。

## 使用方式

工作流程 .github/workflows/tw_marketwide_insider.yml 每天台灣時間09:30和21:30嘗試增量補抓。每次最多160個公司－月份申報，至少間隔2秒。單次失敗不會刪除舊原件；新的成功收據下次不必重抓。官方站台若封鎖查詢，仍可能無法完成全部資料。

離線測試：python -m unittest discover -s tests -p test_insider_marketwide.py -v

執行：python scripts/insider_marketwide.py --max-details 160 --gap 2

輸出：tw-market-data/rankings/insider_marketwide_latest.json 及同名 .md。報告將列出本年已買進的觀察樣本（即使只核到1個月），按照已觀察買進量／股本比例暫時排列，並標示已核對月份及待補月份。未全市場掃描前**不可稱為正式全市場排名，也不可稱為全年累計總買進**。

## 尚待驗證

- MOPS 端點可用性、較早月份是否仍能查詢、欄位是否變動及 GitHub runner 是否受流量限制。
- 每個月新上市公司的上市時點，特殊股別、持有人帳戶實名的唯一性。
- 所有上市櫃公司的逐月覆蓋率及獨立的身份歸戶人工覆核。

來源：證交所 IRB110 https://siis.twse.com.tw/ ，公開資訊觀測站 https://mops.twse.com.tw/ ，上市櫃發行股數 https://openapi.twse.com.tw/ 。
