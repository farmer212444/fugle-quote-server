## 二、用ROE而非「歷史平均P/B必然回來」推估

本次採用長期穩態等式（需依照股利保留、ROE永久持續、clean surplus，非僅2027單年）：

`justified_PB = (normalized_ROE - g) / (shareholder_cost_of_equity - g)`

這是**永續階段條件估值**，不是對2027/12/31價格的預測。假設永續成長 `g=2%`、分公司股東要求報酬率9.5%–12%、2026Q2每股帳面淨值不變作為估值代理。用2027**初步研究EPS**／2026Q2 BVPS測得單年代理ROE；只有假設這個ROE可永久維持，才可把它轉換為長期合理P/B。

數字敏感度存在**主觀不確定性**：
- 鈺齊4.92 EPS與中傑3.53 EPS是先前 V8.10.5/PR86 的自主Base，但營收、GM、廠房成本及股數條款的完整獨立認證仍未過。
- 寶成4.6、志強5.0、豐泰5.4是先以2025實績/2026已公布獲利當錨的**自主研究假設**，尚非完整營運橋接可稽核的2027 EPS預測，不能聲稱模型已全數獨立查核。
- 2026Q2 BVPS以已公告資產負債表使用的參考值（寶成63.46、志強73.51、中傑72.92、鈺齊67.72、豐泰23.95），2027淨值增減/股息/外幣換算/新股CB稀釋都還沒有驗證。
- 9904寶成含香港裕元、寶勝、通路與轉投資資產，不能直接視為純粹製鞋代工的ROE和帳面可分配淨值。
- 由於是長期ROE估值，這組合理PB可能與先前用2027 EPS×PE算的一年期合理價**明顯不同**。切勿取簡單平均或選偏高的一個宣稱市場錯殺；那代表假設完全不同。
- 成本股權要求報酬率每變動2個百分點，合理P/B可能大幅變化；原始研究報告另列＋／－2個百分點的PB敏感度。

### 哪幾檔值得繼續查？

1. **鈺齊9802**：10年PB真正新低，與過去同業自身估值差異最大之一；但2026Q3毛利13.23%使2027 EPS可持續性有疑問。應先驗證新廠量能和費用率，不能只照中位1.88倍估上漲。
2. **寶成9904**：目前0.42倍，模型假設的長期ROE門檻僅約5.15%，在本研究中**帳面估值安全邊際需要的獲利門檻相對較低**。但必查轉投資子公司、分部ROE、香港零售與匯率，確認淨值可回收與股息能力。
3. **志強6768**：0.85倍接近2021上市後低點，但ROE回報若僅6.8%則在11.5%的股東權益成本假設下難支撐0.85倍；要驗證新訂單、產能與2027EPS。
4. **中傑6965**：2025年3月才上市，P/B歷史只有不到2年，不能以0.88倍稱十年歷史便宜；2027獨立BaseEPS3.53反映長期ROE代理不到5%，需確認營運獲利恢復是否可超越。
5. **豐泰9910**：2.83倍接近10年低檔，歷史中位7.18倍不是合理的立即目標，品牌集中、風險折現率及ROE結構與寶成不同。若ROE持續高於股本成本，溢價PB可能有合理性，但需持續核對Nike拉貨與利潤率。
