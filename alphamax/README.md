# AlphaMax V1.0 — 獨立選股研究 MVP

此專案不匯入既有模型、不讀取舊因子權重／門檻／股票排名，不修改根目錄 VERSION 或既有排程。Python 3.11+，只用標準函式庫。

## 執行

```bash
python alphamax/demo.py
python -m unittest discover -s alphamax/tests -v
python -m alphamax.engine alphamax/examples/synthetic.json --output /tmp/alphamax-report.json
```

`examples/synthetic.json` 與 `synthetic-report.json` 全為人工案例，決策期間 2017-01-02 至 2024-01-02，結果截至 2025-01-04。不是台股歷史實證、不是推薦名單。程式版本 1.0.0；每份報告自動包含執行引擎 SHA256、輸入 SHA256、資料期間、全部成本設定及尚未驗證項目。成本可透過 `--costs costs.json` 覆寫，欄位見 `Costs`。

## 固定研究設計

第一個可稽核假說是單因子動能。`momentum` 定義為訊號日前最後完整 12 個月、未含未來調整的總報酬率，必須由上游提供當時可得原件。訓練樣本動能中位數作為當期選股門檻；所有達門檻者等額分配，不引用任何舊模型參數，不依測試結果選最佳門檻。僅能視為候選假說，尚未完成策略有效性驗證。

每個決策日做 expanding-window 時序樣本外測試。訓練批次必須較早，且其中**每一檔**的 12 個月報酬標籤公布日嚴格早於測試決策日；重疊標籤被排除，不隨機切分。持有期間至少為進場後 12 個曆月；供應者須提供週年日當日或之後首個交易日的出場紀錄。引擎驗證時間順序與最低期限，尚未接官方交易日曆驗證是否為第一個交易日。

12 個月預測為已成熟訓練選股之「扣成本個股報酬」經驗分布：p10／p50／p90、虧損機率及樣本數。每折保留當時預測與實現結果、尾端命中紀錄。無參數常態假設；未證明已校準，不能解讀成投資組合信賴區間。資料量不足時仍顯示樣本數，禁止宣稱穩健。各批次可能重疊，不能串乘為淨值、年化績效或用來宣稱獨立樣本數。

兩個基準同時輸出：歷史當期全樣本等權持有（相同成本與成交規則）、零利息現金。尚無可稽核的官方指數含息序列接入，所以不宣稱勝過台股大盤。

## 交易假設

每檔獨立 TWD 100,000 元、1,000 股一張；手續費雙邊 0.1425%、最低 20 元，普通股票賣出稅 0.3%，雙邊滑價 0.1%。這些是明示可配置的台股普通股研究情境，未驗證逐期法規、券商折扣、ETF 或當沖稅別。不可將不適用商品混入。滑價作用於價格，手續費與交易稅作用於實際成交金額；保留整張限制下的未用現金。

停牌、漲停無買方可成交量或零量買不到，整個配置留現金，不事後補買、不重新分配給贏家。出場受阻不假造賣出，以終值零作保守減損情境，仍列在分母。下市須提供已核實每股回收款（可以為零），不以最後股價冒充可成交價。股息為原始持股每股稅前現金、保留現金不再投入；下市回收款不虛構交易所賣出成本。未實作部分成交、成交量容量與公司行動股數變更。

## 歷史資料契約與拒收規則

輸入為 JSON，完整範例可見 `examples/synthetic.json`。日期均為 `YYYY-MM-DD`，語意為台北日期、決策在當日收盤及資料公布後；若無法證明同日資料在決策前已可得，供應者應將 available 日期推至下一日。尚未提供盤中時間精度。

- 根層：`kind`（synthetic/historical）、`source`（原件或不可變封存清單）、`unverified`（非空待驗證事項）、`cohorts`。
- 批次：`decision`、`universe_available`、`universe_source`、`includes_delisted`、`rows`。必須提供當期歷史成分而非目前存活股票，後來下市者仍留在 rows。
- 個股：`symbol`、`feature_period_end`、`feature_available`、`feature_source`、`momentum`；不得把晚公布修訂版倒填至早期。
- 結果：`entry_date`、`exit_date`、`label_available`、未還原 `entry_price`／`exit_price`、`dividend_per_share`、`entry_status`、`exit_status`、`settlement_verified`、`outcome_source`。

拒絕未來特徵、未來股票池、重複批次／股票、NaN／無限值、短於 12 個月標籤、無來源、無核實下市款及無成熟訓練資料。實現報酬只用於該折事後評估，不參與當期選股或預測。

這些是資料契約檢查，**布林聲明與來源字串不是原件稽核證據**。真正 historical 資料仍需逐筆核實公布時間、修訂原件雜湊、歷史成分完整性、下市清算、交易狀態與公司行動；引擎不會把通過結構檢查標成已認證。缺資料不得刪除該檔或以今日存活名單替代，應停止該資料集的正式績效發布。
