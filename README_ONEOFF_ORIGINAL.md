華東兩項合計1,103,922仟元，各有獨立會計列及現金流反向調節，逐項勾稽後只加總一次。未取得原件時先暫停該公司點估值，不重用已知含處分利益的舊基準。原Base 84.2861元、剔除兩項後34.2480元，11/9收盤37.20元下價差約-7.9%；這是同一組其餘假設的研究對照，不是合理價認證。

華東剩餘業外仍包含644,978仟元的金融資產公允價值損益（PDF第52頁，現金流第12頁另行勾稽）。此項只揭露為可重複性未驗證的波動利益，本輪未將它混入處分利益重複扣除，亦未認證其可持續至2027年。報告保留警示及原有業外歸零敏感度；經常性損益、稅務與歸母比例完整重建仍待完成。

精英現金流調節表的括號737,961是減除處分利益的調節項；轉為損益方向時反轉一次。該文件中文字的原生字型對應異常，已以視覺核對公司、合併報表、114年度欄位、仟元單位及處分利益列，並綁定完整PDF雜湊；不宣稱原生文字可獨立驗證該文件身分。所有選取金額都由程式在固定頁面與欄位位置重新讀取，不只信任手填數字。

設定檔 `tw-market-data/config/oneoff_original_v1.json` 保留公司原件URL、完整PDF SHA-256、頁數、選取欄位及核對時間。擷取器封存完整原件gzip，核對首次實際擷取與審查時間，不把新審查回填到歷史預測。舊年度已不再作為基準、或已使用其他分項／TTM調整時，不再機械扣除同一筆；原件或基準不一致則停止該公司目前的可比較估值，不退回舊的高估情境。

原件由既有研究工作流程在估值前擷取、驗證並隨主分支資料提交保存，沒有新增排程。華東原件及實際擷取收據一併封存；已封存且雜湊、選取欄位均一致的原件直接重新核對，保留原擷取時間。網站回傳HTML時拒絕入模，不能把錯誤頁當成財報。

每份收據新增逐公司審查設定的SHA綁定。擴充新公司不會使其他已核對的收據失效；舊版整份設定綁定僅在凍結的 `oneoff_original_legacy_v1.json` 雜湊相符、且該公司設定逐欄未變時才相容。新增審查或擷取時間晚於估值時點，一律不回填歷史結果。金額、來源或該公司版本改動仍會隔離，不能由舊收據取得通過。

排名改變後，`scripts/refresh_top10_sources.py` 會核對當前Top10是否都已納入原件查詢範圍，保留所有舊的追蹤代號，補查新進公司並重跑完整核心報告，最多三輪。未穩定或擷取失敗即停止發布；查詢沒有匹配仍不等於公司尚未公告。這次新進振曜已有Q3公告，因此另做季度更新，與三筆一次性利益修正分開追蹤。

振曜補查時發現舊全年業外分項為null。新摘要接入會保留原先已採用的半年分項年化基準，並明示季節性未驗證；缺少全年分項不再造成整個模型中斷，也不因缺項而恢復未核對的全年特殊收益。

倚天酷碁補查時，官方彙總的非控制權益欄空白，但合併淨利及歸母淨利均有數字且可與MOPS公告勾稽。缺漏的輔助分項維持未知並加入警示，不填零；已提供但對不上的分項仍會隔離公司。核心損益欄位及正式品質門檻未因此放寬。

前次以11/6收盤價及相同其餘假設對照：百容Base由70.74變為8.14，精英32.73變為11.84，綠界76.53變為41.08；三檔退出Base價差前十，其他2,001筆追蹤結果Base不變。本輪再以11/9股價驗證1,409筆同時有Base的結果，僅華東的Base數值改變；新進榜公司的季度更新另外核對。這些是來源修正對照，不是實證投資報酬。正式A+、非經常損益完整審查、現金品質、歷史PIT與機率加權期望報酬仍未因此通過。
