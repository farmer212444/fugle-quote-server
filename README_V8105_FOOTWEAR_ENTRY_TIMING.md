# V8.10.5 製鞋業最佳買點：獲利轉折「營收→毛利→營業利益」可稽核研究

**研究截點：2026-10-23。未自動買股、未改動正式13品質門檻、2027獨立Base EPS/PE與Exit。**
這是兩家公司（9802、6965）的**階段診斷**，不是全製鞋產業回測或模型已證實可打敗0050。

## 1. 不以日曆直接預言最低點

不能機械地斷言「2027 Q1一定是最低買點」。
更可靠的先後順序：

1. **跌深＋內部人市場連買（提前布局A，研究觀察）**：買得可能早，也可能陷入持續壓低毛利的景氣循環。
2. **新訂單開始貢獻毛利**：最近**已公開**獨立單季 GM 較前季改善至少1.00個百分點，且營業利益也較前季提升；不得使用當季尚未公布數字。
3. **2027合理價能支持上漲且成交可行**：以獨立前瞻 EPS×合理PE、現金流及股數稀釋測試算合理價；若早已漲破合理價，即使利潤轉折亦不能追價。

跨年度比較可防止只是傳統季節性旺季高於淡季，不可把Q1→Q2改善稱為整個2027年度已復甦。

## 2. 截至2026/10/23可公開核對的季度利潤橋接

公司資訊（新台幣**仟元**，非張數）：

- **9802 鈺齊**：
  - Q2收入5,258,501；毛利732,887；營業費用471,801；營業利益261,086；GM13.94%，EPS0.89。
  - Q3收入5,435,935；毛利719,347；營業費用491,896；營業利益227,451；GM13.23%，EPS0.68。
  - Q3較Q2營收增加177,434千元（1.77億元）、毛利減少13,540千元、營業費用增加20,095千元，因此營業利益下降33,635千元（3,364萬元）。
  - Q3較**去年同季**營收增加1,616,549千元（16.17億元）、毛利只增加48,861千元（4,886萬元）、費用增加119,656千元（1.20億元），營業利益**反減70,795千元（7,080萬元）**。增量毛利/增量營收僅**3.02%**。
  - 處於「營收增加，但新增訂單獲利轉化不足」；內部人加碼+252日低檔兩因子研究初篩已到位，**不能說獲利已見底**。
  - 下一個「強確認」的研究指標：在下一份公開單季報告中，GM至少**14.23%**（13.23+1pp）、營業利益高於227,451千元，並且沒有不利費用與現金流惡化。*此門檻純研究設定，非公司指引、非買進指令*。
- **6965 中傑**：
  - Q1營收4,785,000；毛利481,000；營業利益**-81,000**；GM10.1%、EPS **-0.64**。
  - Q2營收5,663,000；毛利723,000；營業利益**+151,000**；GM12.8%、EPS **+0.30**。
  - QoQ營收+878,000千元（8.78億元）、毛利+242,000千元（2.42億元），營業利益**改善232,000千元（2.32億元）**、GM+約2.7pp。
  - 但和去年同期相比，Q2營業利益僅由145,000千元增至151,000千元，EPS從1.33降到0.30；不能把Q1→Q2季節性反彈當作全年持續性改善。
  - 下一步等待**2026Q3**實際季度財報，核實GM、營業利益是否維持正值及營運現金流，再決定是否從研究確認升級。

## 3. EPS敏感度（純假設，不是2027EPS預測）

以9802 Q3營收約54.36億元且維持不變、已發行股數採**2026-10-22**2.0099億股、稅後保留80%和費用不變：
- GM每提高1個百分點→單季增量毛利約**5,436萬元**；
- 假設增量全部轉成稅後淨利，則單季EPS機械增加約**0.216元**；
- 四季都一樣時年化約**0.865元EPS**。

此為`收入×1%×0.8÷股數`的敏感度，不能解讀為公司真的會提升1pp、2027所有季度營收一致、費用不增加、公司稅率20%、無股數稀釋，或股價一定上漲。
