## 官方選股框架：不可簡化為40/30/30即能復刻

PDF規則中：

- 採**TWSE上市普通股**為母體，先檢查市值至少25分位以及ADTV流動性不超過10交易日，ADTV涉及假定60億基金規模、單股90日平均量。
- 其後若股票佔採樣母體市值權重 **≥1%**，會無條件納入；其餘候選以綜合因子分數前四分位（≥75分位數）篩選。不能把「中小型股全部需要達到前25%」當一體適用規則。
- **品質因子40%**：非金融包括ROE、五年EPS變化標準差（負向）、OCF／資產、毛利／資產、負向槓桿的標準化分數；金融股有不同定義。
- **價值因子30%**：非金融包括OCF／股價、EBITDA／EV、EPS／股價、股東收益率，逐指標標準化且經裁切。
- **動能因子30%**：0.5倍標準化股價動能、0.5倍標準化盈利動能；價格動能使用資料截止**前一個月底**的還原價，比較前7個月、前13個月底並依3年週報酬波動調整；盈利動能 = （近一季EPS－前一季EPS）／**截止日收盤價**。
- **缺乏同期完整母體、公司行動還原價、財報PIT、原版Z分數和規則版本**，不能計算官方00905當日品質/價值/動能確切分數，更不能說「00905就是看壞新廠」。

2025年第一季的自結新聞稿在4/22已公開；為避免把**未獨立存證**的實際秒級發佈時間視為確定性，研究資料以 \`2025-04-22T23:59:59+08:00\` 當保守起始可得時間。

## 如何驗證00905剔除策略「真的有用」

將**同次26檔被剔除**及**44檔新增**加上所有維持成分股票作成**同日期PIT追蹤母體**，按2025/7/17後 1／3／6／12月，以除權息還原與流動性／交易成本比較；不能只選9802這個事後成功案例。每期季度定審應包含**所有換入換出與存續股票**，也要記錄已下市、更名及無法成交的股票，並和原V8.8模型及大盤對照。只有完成樣本外測試、避免幸存者與多重檢定偏誤後，才能賦予ETF剔除風險統計權重。
