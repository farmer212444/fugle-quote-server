# 歷史原件擷取修復：單一公司試驗

直接擷取 SEC 完整申報、SEC 官方 API 及公司公告 HTML 的實測均收到 HTTP 403。這些失敗已保存在分支的來源狀態檔與 Actions 紀錄，沒有轉成財報數值、零報酬或正式認證。

本次改由公司公告頁面上的下載連結取得六份台積電官方盈餘公告 PDF，保存完整原件、實際擷取時間及 SHA-256。`config/issuer_pdf_downloads_v1.json` 記錄官方公告頁、當時可見的 PDF 下載網址與原件路徑。原件驗證可完全離線執行，毋須反覆碰觸失敗端點。

```sh
python -m pip install pypdf==6.21.4
python scripts/issuer_earnings_intake.py --offline
python -m unittest -v tests.test_sec_pit_intake tests.test_sec_api_intake tests.test_issuer_earnings_intake tests.test_issuer_pdf_originals
```

程式從 PDF 本文重新核對發行人、公告日期、季度、幣別、普通股稀釋 EPS、合併收入與淨利；PDF 的日期欄位若有文字片段間距，只在該日期欄位處理。普通股 EPS 與 ADR 數字分開解析，年度不會取自擷取日期。

另以 2024-10-18、2025-01-17 兩個截止時點重算當時已公告四季 EPS 的加總。只有日期的公告延至次日使用，缺季與觀察到的版本衝突會被拒絕，後來的季度不會寫入較早時點。季度稀釋股數可能不同，這個加總不宣稱等於精確年度稀釋 EPS。

## 此修復的範圍

- 六份原件、六個財報期別、一家公司；不是全市場歷史母體。
- 兩筆日期隔離的 EPS 算術重播；不是兩筆股票報酬回測。
- 今日下載的官方文件可以核對本文與公告日期，仍未證明當時版本、完整修訂歷史或歷史投資可得性。
- 不會產生 2027 機率、期望報酬、報酬排行榜或正式 A+。

## 尚未完成的投資驗證

仍須補齊當時財報版本、上市與下市母體、完整公司行動與含息報酬，並實際執行同一估值方法的訓練與保留期驗證。現行 `EMPIRICAL_TERMINAL_WEALTH_V1` 的 12 個訓練及 12 個樣本外、不重疊窗口，是未經實證驗證的研究政策；不能宣稱是通用統計最低要求。固定到期日也不能因每天新增一筆預測就增加獨立年度樣本。取得本次六份 PDF 並不解決這個校準設計問題。

在上述證據未通過前，模型仍是研究原型，可信的 2027 機率加權期望報酬尚未完成。
