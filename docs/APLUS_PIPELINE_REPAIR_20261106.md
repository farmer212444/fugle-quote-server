# A+ 收盤掃描與認證流程修復

2026-11-06 的研究工作在自我測試出現 3 項失敗、5 項錯誤，後續來源刷新、估值與發布全部跳過。沒有產出當日認證報告，不能解讀為當日全市場沒有 A+。

## 修正

- 當兩個交易所的 OpenAPI 同時落後時，依臺北時間、14:20 發布下限、週末及已有時間證據的休市紀錄，向官方指定日期端點補抓。日期只決定請求；來源必須實際回傳該日行情，兩市場全部成功才發布。
- 0056 金融股研究採用估值快照所消費的指定日期行情及 SHA256，避免最新行情已更新、舊快照仍在時，全體測試因日期不一致而停止。原件變動、缺少或重複收據仍拒絕處理。
- 目前來源的整合測試使用目前查核時間；歷史可得時間測試保持原截止時間。凍結快照 CLI 測試使用與合成資料相符的測試時鐘，不修改正式擷取時間或七日新鮮度保護。
- 低流動性與未入模測試補齊實際成交金額欄位；不恢復「收盤價乘成交量」替代值，缺少金額仍不得入榜。
- 主報告新增 `certification_diagnostics`：逐項有效 PASS／FAIL／PENDING、完成 13 項判定的公司數、僅符合 30% 價差的研究候選數，以及共同回測與行情缺口。

## 認證門檻

A+ 仍要求 Base 價差至少 30% 及原有 13 項品質門檻全部有效通過；A++ 保留 35% 與壓力測試。沒有簽發新證書、把 AI 蒐集資料當成人工來源簽核，或把會計預測測試當成投資績效。

`CERTIFICATION_INCOMPLETE` 表示認證工作尚未完成。已認證數量為零不代表全市場已完成審查或沒有投資機會。官方來源無法取得、原始證據或樣本外投資績效缺件時，保留具體原因。

## 驗證

執行 `python scripts/tw_v880_run.py --self-test`；另按既有工作流刷新官方來源、核對收盤原件雜湊、執行核心研究、凍結快照及觀察驗證。測試涵蓋兩市場同時落後、單市場落後、早盤與週末、已知休市、第二市場失敗、缺失與竄改行情收據，以及價格符合但品質仍待驗的情況。
