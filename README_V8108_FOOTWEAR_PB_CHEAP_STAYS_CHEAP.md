# V8.10.8 製鞋股「股價淨值比低估會維持多久」實際驗證

**來源及時間：** TWSE 官方逐日 P/B 2016-10-24 至 2026-10-22，對寶成、鈺齊、豐泰完整十年，對志強(2021上市)與中傑(2025上市)僅計上市日起；共 **9050筆有效逐日P/B**，對 **450月原始HTTP封存／SHA256** 全部重新覆核。2026-10-24研究編製，歷史查詢是事後取得的原始官方結果，**不能假裝當年逐日即已PIT抓取**。

寶成從**2023-03-17起至2026-10-22**，已連續**875個交易日**P/B低於1倍，至觀察日仍沒有恢復。10年資料中全部低於1倍的占比**63.0%**；寶成等於證實「折價可以長期維持」，沒有因0.42倍就必然很快漲到1倍。

相對地，鈺齊10年2,438交易日中僅**27日**低於1倍（約**1.11%**）；10月19日至22日最新連續4天，其此前9月10日至10月15日另一段連續23日。**2026-10-22 0.92倍亦為10年最低**，與「長期習慣性低於淨值」的寶成不同，是近年相對突然的估值異常。但價格若繼續跌、未來Q3毛利率未改善，PB可以跌破0.92倍並形成新的最低，不能稱「此價絕對底部」。

## 2. 歷史低P/B後的一年P/B變化：不能誤稱股價勝率

**警告：這張表不是股票總報酬績效！**
- 分子分母是 **P/B數值**，不含當期帳面淨值變化造成的股價絕對波動、股息、股權稀釋、分割、現金增資、實際價差、稅費或0050含息報酬率。
- 每檔真正成熟樣本數只有0–5個事件，完全無法給出統計顯著性或明年成功率。
- **9802在2026年跌破1倍是近期才發生，後續252日根本尚未成熟，不能宣稱「歷史PB<1後一年跑贏大盤X%」**。同理6965上市年期太短沒有足夠成熟觀測。
- 固定門檻P/B<1「從上往下穿越」的事件中，9802和6965均**0筆成熟一年觀察**；不能把未成熟未來事件算失敗或勝利。
- 追蹤獨立事件避免大量共線樣本，不代表已完成真正可以成交的前視PIT/含息扣成本ETF基準回測。

## 3. 現價PB與ROE揭示的核心分歧

參考先前 **V8.10.7主觀長期持續ROE** 估值，寶成0.42倍P/B大約需要長期ROE **5.15%**（假設 Ke9.5%、g2%）；鈺齊0.92倍大約需要長期ROE **10.74%**（Ke11.5%、g2%）。

以**2026Q2帳面每股淨值**換算，現有P/B維持需要的*每股常態年盈餘代理*：
- 寶成：63.46 × 5.15% ≈ **3.27元**。
- 鈺齊：67.72 × 10.74% ≈ **7.27元**。
- 而鈺齊的PR86 **2027主觀Base EPS≈4.92元**，低於上述**假設永續ROE的每股盈餘要求**，並不符合「只要PB=0.92就被低估」的武斷推論。
- 這只是估值假設一致性；永久持續ROE與2027單年復甦利潤不一樣。上市公司合理評價也可以包含後面數年的獲利改善，因此不能用此計算直接斷定必跌或給未來股價的唯一合理價。

### 結論與下一個驗證門檻

**鈺齊優先研究估值異常，寶成優先研究低ROE折價的持續性。** 製鞋業低PB已經很罕見，但**壓力在於製鞋廠能否轉虧／從低毛利恢復，而不是能不能找到史上最低數字**。應優先驗證：
- 鈺齊2026Q3 GM約13.23%能否於未來連續季度回升、營益率能否同步轉強、2027 EPS是否可上修至合理PB所需ROE及該現金流能否留給母公司。
- 寶成必須拆解香港裕元/寶勝與通路、經常性ROE及母公司股東實際淨值，避免PB 0.42倍成為**長期價值陷阱**。
- 其他上市年期未滿10年同業，僅上市後統計，不能套用完整十年PB分布。
- 嚴格一年「買進當天價格 vs 0050含息扣成本超額報酬率」仍需完整股價公司行動、實際可成交價格與固定版本出場規則，**尚未完成**。
