- 模型同步計算**+10%額外股數**的EPS與PE價格壓力測試。這是壓力測試，**不是已有公開新股發行證據**。
- Bull反映接近／高於先前年度較好毛利率，並不是新廠一定能達到的結果。Bear風險包括產能低稼動、品牌訂單轉弱、工資/關稅、外匯、資本支出、存貨和現金流。
- 情境權重30%／50%／20%是主觀假設，不是回測校準過的機率；2027實際相對0050一年勝率仍為**null**。

## 五、研究結論

以2026-10-22股價看，**「誰先獲利改善」不等於「誰的投資報酬率較高」**。鈺齊2027年Base的合理價68.92相對62.6僅+10.1%，尚不符合A+門檻；中傑Base合理價52.96反低於64.3，市場已反映較強的復甦假設。兩檔都有Bull大幅回升空間，但Bear成本同樣很高，不能只拿Bull當唯一目標價。保留為研究分支，**正式A+＝0**。
