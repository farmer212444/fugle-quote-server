官方彙總與原始當期數字來源層級分列，並核對當期營收、毛利及營業利益與標準化資料。原始財報附註、歷史明細、缺漏樣本與存活者偏差仍須處理；母體逐家列管不等於全部已有可比較估值。金融業 ROE/PB、交屋／工程認列、通路單位價差與其他專用模型缺資料者繼續保留排除理由。

## 稀釋股數

每次更新六個官方股數／債券來源：上市及上櫃公司名冊、TPEx 國內／海外可轉換及交換債券。使用流通餘額而非原始發行額；單一來源失敗保留原來源與舊日期。空來源、非有限餘額、缺債券身份、錯誤日期或未知幣別不得覆蓋有效資料。

18家、28檔有效外幣可轉債已有合約固定匯率與具日期轉換價。以債券 ISIN、發行人、數值及來源 hash 檢查；匯率不得用即期匯率代替。已知調整價涵蓋鴻海、廣達、緯創、緯穎、新唐。部分仍是有日期的發行價，不能宣稱已確認全部後續調整、員工選擇權或其他潛在股數。

來源 JSON 是數字摘錄與原始擷取 hash 收據，不是原始文件全文或原始位元組的獨立認證；新唐補正價來自原始 PDF 的網頁擷取，明確不附原 PDF 位元組 hash。所有本次法律條件仍為 current_terms_verified=false，完整稀釋股數品質門檻不會因補齊匯率而自動通過。

基本估計分母取「當期實際普通股＋全部債券假設轉換股數」與已披露加權稀釋股數的較高者，避免把已包含的債券再加一次。這是情境期末分母，不冒充會計期間加權平均股數。A++另對 EPS、PE 各減10%，並將 CB 轉換價減10%增加潛在股數；價差非負底線及這組壓測是明列的實作假設，原 A+30%／A++35%／Discovery25%門檻不變。

## 成長推估與驗證

成長持續係數原以已知九個月占大部分的全年誤差選定，容易把高成長產業的未知季度成長壓至零。改以尚未發生的獨立第四季誤差擬合，排除非正的剩餘季度或重編不一致樣本；2025年訓練後固定係數，以2026Q1已知營收加尚未發生Q2預測檢驗。2026保留期不參與選係數。

輸出同一獨立Q2樣本、同一預測式下的新舊係數 MdAPE/WAPE，以及成長≥20%的預先定義子群。全體1781家 MdAPE 12.53%→12.38%、WAPE 23.86%→18.51%；電腦及週邊107家係數0→0.5，MdAPE 23.66%→16.79%、WAPE 33.82%→18.03%。改善不是每家公司都保證成立，也不是股價或投資報酬準確率。

2027全年仍是此外推情境，尚缺逐家產能、訂單、ASP、產品組合與成本推導及完整年度樣本外驗證。既有毛利恢復假設另標未驗證，不能用這裡的營收誤差替它背書。原始公告／修訂PIT及歷史上市下市母體未完備，投資回測績效繼續留空。
