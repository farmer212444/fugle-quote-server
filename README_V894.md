# V8.9.4 營收領先發掘層

目標是避免等到毛利率與EPS完全確認後才發現復甦股。月營收先用於研究排序，季度毛利、費用、現金流與稀釋資料則繼續修正估值及執行正式13項品質認證。

## 分工

- **早期發掘**：月營收年增率35分、相對YTD加速度25分、已觀察的YTD持續性10分、多月連續性10分、估值尚未反映20分。
- **資料保守性**：目前公開保存檔只有2026年9月單月快照；多月連續性不得推定，先給0分並標示待補。
- **風險否決提示**：YTD衰退、單月大幅月減、YoY相對YTD明顯減速、缺可比估值都明列旗標。
- **可比性隔離**：建案交屋等跳躍認列及月／YTD年增逾500%的極端低基期比率保留人工覆核，但不進可比Top20。
- **正式估值與認證不變**：不自動提高毛利率、EPS、PE或Base；A+仍須Base漲幅至少30%且13項品質全過，A++仍須35%及壓測。
