# V8.9.9｜逐日對帳的成交值證據銜接

## 發現的具體障礙

6206 飛捷與 9802 鈺齊-KY 的上市個股交易歷史備份（TWSE，每月原始來源）到 **2026-10-16** 為止，但模型的正式參考收盤資料已存入 **2026-10-19**，含兩檔的實際成交金額。舊 `issuer_backfill_probe()` 要求歷史備份最新日恰好等於估值參考日，因此把已存在的74個歷史交易日直接判定為 `PENDING_REFERENCE_SESSION_MISSING`。

## 本次修復

- 把歷史逐筆成交金額與 `price_archive()` 已完成 SHA 驗證的市場每日正式收盤檔，依證券代碼及交易日期合併。
- **同日交叉查核**：若兩份官方來源成交值不一致，顯示 `SOURCE_CONFLICT_REVIEW_REQUIRED`，不覆蓋、不平均、不計算20日成交值為已查核。
- **禁止偷看未來**：參考日後的資料一律拒絕，也不將缺失交易日補為0或推算成交。
- **真正20筆有效交易日**：完整20個有效紀錄才計算中位成交金額及理想化20%參與率下的退出天數；仍需價差、漲跌停、深度與真實可成交能力的獨立覆核。
- 原本的13項正式門檻及全部正式認證旗標不變；這只會從缺來源升為 `SOURCE_CAPTURED`，**不會取得 `tradability` 的正式PASS**。

有使用真實封存2026-10-19官方價格與6206、9802月歷史的回歸測試，也包含數值衝突與未來日期測試。
