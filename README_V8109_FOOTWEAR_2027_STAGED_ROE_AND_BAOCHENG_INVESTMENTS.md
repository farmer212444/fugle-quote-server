**研究截止：2026/10/24；股價：2026/10/22官方收盤；淨值：2026Q2已公開財報。**

本報告是在 V8.10.7／V8.10.8 的450月份、9,050筆TWSE每日P/B原件認證之上，進一步改進「只看歷史折價即認定明年會回升」的錯誤。不修改正式主模型、不下單、不是A+、不假造2027已發生的市場報酬。

## 發現二：9904寶成不是單純製鞋P/B，涉及南山人壽IFRS17

2026H1公司公開資料中：
- 合併營業外淨損益 **+65.64億元**，其中採權益法認列投資收益 **62.43億元**；南山人壽相關轉投資收益 **約54.43億元**，報導指出直間接持股約18.09%。來源：[2026/08/13寶成財報公司說明](https://ec.ltn.com.tw/amp/article/breakingnews/5539146)、[詳細報導](https://money.udn.com/money/story/5710/9690538)。
- 南山人壽自2026年適用 **IFRS 17**，權益法導致寶成相應重編前期2025年財報。故「2026年的每股淨值與10年P/B歷史中位」不一定是**完全同會計基礎的序列**，不可用10年中位0.82倍直接斷言2027會回去。
- 公開財報權益變動摘要顯示**歸屬母公司股東2026H1其他綜合損益+487.37億元**，占2026/06/30母公司股東權益1,870.16億元約26.06%（注意：是總體其他綜合損益，不是全部可直接歸因南山人壽）。[2026Q2權益變動表二手整理](https://toalpha.tw/stock/9904/filings)。
- 如純粹為敏感度而將2026H1母公司其他綜合利益487.37億元從2026Q2帳面淨值中**假設性扣除**（**不是正確的正式淨值**）：寶成BVPS會由**63.46元→約46.92元**，P/B由**0.42→約0.562倍**。這只是示範帳面估值對綜合損益敏感，不能被當作資產永久損失或真實重編淨值。
- 上半年的南山相關投資收益不能**不經稅、母公司歸屬及被投資企業淨利考量，直接從EPS扣除**；但其大額影響代表2027年EPS4.6元假設與長期ROE6%需要獨立跨部門複核。

## 新模型：五年ROE逐步變化＋殘餘利益法

相較 V8.10.7 把2027單年EPS/BVPS當作**永久ROE**，本次逐年計算2027至2031年股東權益、盈餘與股利；終值起點為2032年永續ROE和成長率。對年份t：

`ResidualIncome_t=(ROE_t-Ke)×B_{t-1}`

`Value_2026Q2=B_0+Σ_{t=1..5}ResidualIncome_t/(1+Ke)^t+[ResidualIncome_{2032}/(Ke-g)]/(1+Ke)^5`

模型內假設未來股數不變、cash payout鈺齊35%／寶成55%、永續成長率2%、股權成本鈺齊11.5%／寶成9.5%、2027年ROE根據各自2027 EPS及2026Q2 BVPS，2028～2031逐年線性轉向長期ROE。**這些全是研究情境，不是公司財測或已校準機率。**

|參數|鈺齊9802|寶成9904|
|--|--:|--:|
|2027研究Base EPS|4.92元|4.60元|
|2027單年代理ROE|7.27%|7.25%|
|2032年以後假設永續ROE|7.5%|6.0%|
|Base的五年ROE殘餘利益合理價|**35.70元**|**34.35元**|
|相對2026/10/22股價|**−42.96%**|**+30.37%**|
|若仍以此2027 EPS為起點，模型反推**支持當前股價**所需長期ROE|**11.64%**|**4.87%**|
|同條件下反推**至少+30%理論漲幅**所需長期ROE|**14.28%**|**5.99%**|

**絕對不能把34.35元當作9904可以放心重押的合理價。** 它依賴集團轉投資大額損益持續、每年股利率與股東權益成本、正常ROE及不發生資產評價回落等強假設，仍需正式品質認證。

本模型會同時計算Bear/Base/Bull以及股東資本要求報酬率±2百分點敏感度；也將本期股東權益、EPS及H1帳面淨利以股數交叉對帳，阻止把少數股權併入母公司股東權益。

### 投資研究結論

1. **鈺齊：** 官方歷史十年P/B創低，但**現有2027 Base EPS4.92與長期ROE7.5%的假設不足以支持現價0.92倍P/B**。未驗證毛利率重回較高水準前，沒有安全邊際的A+買點證據。若2027～2032 ROE真的恢復到11.64%以上，現價才可能有足夠長期估值支撐（依本模型強假設）。
2. **寶成：** 極低0.42倍P/B看似吸引人，本研究穩態ROE只要約4.87%便足以支撐現價；但**南山人壽投資收益、IFRS17重編、487.37億元OCI**意味必須先補齊資產重估風險與本業貢獻，才能驗證2027 EPS4.6／長期ROE6%具可持續性。
3. **沒有任何一檔正式A+**。2027股價會上漲多少及跑贏0050的機率沒有足夠成熟含息扣成本樣本外資料，**不執行千萬元單一股票集中買進**。
