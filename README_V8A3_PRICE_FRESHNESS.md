# V8.A.3｜官方參考股價新鮮度檢核

**已知實際問題：** 2026/10/21上午的模型最新參考收盤仍是2026/10/19，但市場在2026/10/20曾有交易。舊模型資料層只在收盤日超過7個日曆天時才拒絕計算，造成「合法但已落後」的研究股價仍看似最新。

這次新增純函式 `tw_model_v880/freshness.py`，將每次估值的台北本地形成時間與已驗證官方收盤參考日比對，辨識估值中**可能遺漏**的週一至週五交易日：模型運行日16:00以後才將該日算入候選已結束交易日；此前以昨日前的平日為上限。這只是操作時點保守篩選，**不含臺灣證交所休市行事曆**，因此不能直接推論遺漏日期必定開市。

- `latest_research.json` 中新增 `price_freshness` 明確揭露候選缺口、可能落後、來源未獨立認證。
- `latest_research.md` 的Top10前方顯示顯著警示：若有可能遺漏的工作日，所有股價僅為**歷史研究參考價**，不是最新可成交買入價。
- 不用新聞價、推算價、價格補零或跨日補值來消除警示。保留原有可靠股價日期，不改變EPS、合理PE、目標價與13項正式門檻。
- 通過單元測試驗證2026/10/21早上仍用10/19價時，應列出可能缺2026/10/20；週末、週一開盤前、交易後、夏令/時區和假日不確定性都有明確處置。

只有官方TWSE與TPEx日資料真正取得且驗證日期相符，警示才會消失。未建立新的排程、自動下單或自動認證PASS。
