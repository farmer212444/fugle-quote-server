# V8.10.2：資料、估值修訂、部位與投資驗證

2026-10-22。實際版本以根目錄 `VERSION`、`tw_model_v880.VERSION`、程式雜湊及策略設定共同識別。

本版把新公告接入研究估值，保留公司別預測依據，並建立可執行的成交、部位與模型比較工具。這些程式控制不等於已證明投資超額報酬，亦不構成任何股票的買賣委託。

## 新資訊確實進入估計

`events.py` 每次重讀已保存的公司原始PDF，核對發行人、期間、單位、原始檔雜湊、表格欄位與損益算式。使用第一次真正取得原始位元組的時間，不回填成網站顯示的日期。

第一個實際適配器支援9802於2026-10-20發布的2026Q3自結簡表。自結仍屬未經核閱的公司公告，不冒充完整季報。Q3累計減去單季必須與原Q2資料勾稽，去年同期也必須對上；遇到重編差異、未支援表格、未來時間或檔案變更，該公司另列待修，不用舊估值當成已納入最新資訊的結論。

核對完成後，以原有會計預測方程式重算營收趨勢、毛利、費用、業外年度銜接、稅率與歸母比例。沒有新增任意復甦機率。現金流和附註仍沿用其實際資料期間，不能從自結損益補出缺失的CFO。

每筆修訂保留同一模型、同一股價及同一估計時間下「未納入事件」的對照值。以10/20官方收盤資料試跑：9802研究EPS約4.59→4.39，Base約55.06→52.67。這是條件式研究估計，2027產能、單位成本與稼動率仍須公司別證據。

其他公司的公告格式仍需各自可靠的擷取規則；本版不宣稱已讀完全市場公司的法說與財報附註。

## 可重用的經濟輸入認證

`contracts.py` 輸出每家公司13項義務的範圍、具體缺件及失效條件。公司營運、來源、交易可行性與策略驗證分開列管；正式A+仍須原有13項全部通過，30%／35%門檻維持。

新的預測契約 `V810_ECONOMIC_INPUTS_V1` 綁定公司、資料期間、目標日期、營運與股數假設、估值倍數、事件來源及經濟方法雜湊。只換參考股價日期不必重新審核相同營運假設；股價、潛在漲幅與交易能力每日另行計算。輸入或方法一變，舊契約即失效。舊證書仍保留原本的程式／股價日期限制。此契約不取代原始來源及審核要求，不會生成虛構人員簽核。

## 公司別與同業估值

- 製造業營運帳可用四個季度的產能與利用率分別加總，不將年底產能當全年產能。折舊與不含折舊固定成本分列，重複計算會被拒絕。
- `peers.py` 可消費 `evidence/v880/matched_peers/{code}.json`：同一商業模式、同一目標年、同一稀釋EPS與幣別、至少三家不同同業、具日期的原始來源及審閱紀錄。Forward EPS由營運帳計算，不讀券商目標價；循環股需正常化獲利口徑。
- 尚無合格同業帳時保留原有研究倍數並揭露待驗，不用缺件猜出「正確PE」。
- 反推目前股價隱含EPS／毛利率、達到30%漲幅所需毛利率、毛利率每改善1個百分點的EPS敏感度，並列EPS、PE各下修20%的情境。

前20家公司與6206、9802的工作項目會輸出至 `rankings/latest_institutional.json` 與 `.md`。該報告的查核資訊不等於已完成20家公司完整營運帳或正式認證。

## 部位與成交

`portfolio.py` 限制個股、產業、共同風險、情境損失、每日成交參與率與清倉日數。缺少共同風險審核、正的壓力損失估計、正式A+或交易證據時，不以零風險補值。

`config/institutional_research.json` 的1,000萬元與各項上限是明示的研究假設，並非使用者持倉或經校準的最適比例。符合條件的個股可引用具原始來源、期限及相同經濟輸入雜湊的 `risk_profiles`；缺件仍列待補。本次沒有個股完成全部要求，研究配置保持現金。

`execution.py` 使用訊號之後的開盤，逐項要求費用、稅、價差與滑價假設、完整公司行動及可成交依據。股息、分割、買賣兩端參與率分別計算。零成交、未知權利事件、重複日期或缺開盤不會被跳過以美化績效。結果是明示假設下的研究總報酬，不是經紀商成交紀錄。

原每日股價排程新增保存來源中的開盤價及可還原的官方原始JSON；缺開盤仍留空，不用收盤代替。原始資料永久保留於 `prices/originals/`，不只依靠30日工作產物。研究報價不自動取得成交認證。股價工作流僅能從main發布，測試分支不能把程式連同資料推入main。

## 新舊模型比較

`institutional_shadow.py` 在相同資料及時間下另跑「不使用新自結事件」的對照，兩者分別封存，策略識別包含程式及設定。對照無法覆寫正式研究排名，也不會產生正式A+。

模型假說與選股規則寫入不可覆寫的 `experiments/registrations/`；變更假說、成本或模型須另建試驗，不能看完結果再改註冊內容。初始比較固定研究Top10等權重、下一開盤及21個交易時段，不能遺漏虧損股票或更改持有期。這是研究模擬規則，未授權交易。

`validation_io.py` 讀取具來源雜湊的開盤／收盤、公司行動與審核資料，重新計算各組合報酬；不直接信任手填報酬率。`experiments.py` 提供：

- 按時間向前驗證、重疊訓練標籤排除與隔離期。
- 相同日期、成本、持有區間的配對比較；重疊期間不能冒充獨立組合報酬。
- 區塊重抽樣及按已登錄試驗數進行Bonferroni修正，並非宣稱算出PBO。
- 最低樣本、不同市場階段及回撤檢查。試驗資料拒收或樣本不足時不升級、不報勝率。
- 對事先發出的機率計算Brier分數及可靠度分組；不足時不生成機率。

目前還沒有成熟的完整扣成本投資結果，經紀商費率、公司行動與成交佐證亦未完整。初始成本政策因此為空，不能事後補成本並把過去結果說成當時已預註冊。機率、預期淨報酬與正式回測績效仍留空。

## 執行與發布

沿用既有研究工作流與股價更新，不新增重複排程。

```bash
python -m pip install -r requirements-model.txt
python scripts/tw_v880_run.py --self-test
python scripts/tw_v880_run.py --target-date 2027-12-31
# 既有證據與品質報告依原研究工作流更新
python scripts/institutional_shadow.py
python scripts/institutional_review.py
```

三個輔助稽核會先檢查快取的版本、程式、來源清單、公司帳與原始資料雜湊；過期時從已驗證來源重算，現行快取則直接共用，不再因舊版本輸出使稽核中斷。原工作流的發布重試縮排已修正；兩份舊診斷的版本限制也已在核對資料契約後明確加入V8.10.0，未知版本仍被拒絕。研究報告不再誤寫未經公司推導的毛利恢復已加入Base。

可驗證的資料、可追溯的預測與可重現的風險計算，是本版已增加的能力。投資優勢仍須足夠的樣本外、扣成本結果證明。

## V8.10.1 正式環境驗收修正

一個升級前已在執行的工作流，在發布重試時取得新版程式，卻沒有新版PDF套件；它正確隔離9802，但產生了套件不可用的研究快取。本修正將實際套件版本列入輸出、策略識別與快取核對，套件狀態不同即從來源重算；套件需求檔也加入程式／方法雜湊。發布重試每次取得最新程式後會同步安裝該版本套件，避免程式與環境漂移。這項修正不放寬資料或認證門檻。

## V8.10.2 快取與事前封存修正

已重現舊快取在改查2028年時仍回傳2027年結果、新增部分歷史財報時未觸發重算，以及事後封存只因估計標籤較早就被接受為事前模型的三類缺陷。

- 快取現在核對明示目標日、台北評估日期、同日價格新鮮度警示，以及審核到期／來源開始可用等時間邊界。過去時間查詢不能沿用未來估計；不同日期重算仍須原始資料真正可得，並未補造歷史PIT。
- 來源狀態包含動態新增、刪除或修訂的財報、詳細損益與12月營收，以及證書、CB條款與公司公告連結的原件位元組。缺失原件亦記錄其路徑，補齊後會失效重算；CB及12月營收增加實際消費收據。
- 簡表與完整結果須通過壓縮檔及JSON雙雜湊、模型／時間／目標／來源／正式數量／母體一致性檢查。損壞的快取從已驗來源重建；重建後仍不一致會明確失敗。
- 樣本外結果要求實際封存時間和估計時間都不晚於訊號，不接受結果揭曉後才封存的模型；封存收據的模型、策略、財報及價格身份須與已封存內容相符。收據時間仍是系統記錄，並非外部公證時間戳。

本次保留原有估值方程式、30%／35%門檻與13項證據要求。單元測試與真實已存資料的管線重現分開記錄，不把工程測試通過當成投資勝率。沿用既有GitHub工作流，不新增排程；未完成的原始附註、營運橋接與真實扣成本樣本外證據繼續列待驗。

## 2026-10-22：13項認證逐項驗收與實際障礙

`v891_gate_certification.py` 原先只要同一公司的證據包有一項缺件或過期，就拒絕全部項目；而新包被拒絕時，先前輸出的證書可能仍留在現行目錄。現在每項仍須通過原來的原始檔雜湊、來源身分、時點、具名核閱及判定理由檢查，但有效PASS與FAIL可獨立驗收。不合格項目明列原因；新包取代舊包時不合併舊PASS，全部拒絕則撤下該包舊證書，歷史版本留於Git。這不會自動填寫核閱人或把下載收據升級為認證。

進度報告改讀取雙雜湊驗證的主模型完整結果及其**實際有效門檻**，不再跳過主模型的自結財報、預測輸入、稀釋股數與核閱範圍檢查而另行認證原始JSON。統計區分PASS、FAIL、PENDING及尚未進入判定；缺估值的關注公司仍列出。原件損壞逐家公司隔離，已決門檻的來源位元組亦重新檢查，不能把來源錯誤藏在一般待驗文字中。

以修正前已封存的2026-10-22 10:11台北時間快照重現：追蹤1,998家，可比較研究估值795家；1,336家有13項模型判定、662家尚未進入判定。各項有效PASS及FAIL均為0，正式A+仍為0；這表示認證未完成，不代表全部公司品質失敗。鈺齊截至2026-Q2的8季PDF已有8/8期標題覆蓋，但全文附註、來源身分與公告PIT仍待核對，Q3自結不等同完整核閱季報；飛捷永久原件目前是3份法說簡報，不能取代8季財報。樣本外檢查目前亦沒有完整扣成本總報酬樣本。以上是實際證據缺口，本次程式修正沒有宣稱已補完。
