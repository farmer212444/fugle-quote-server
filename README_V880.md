## 修正

- 以營收→毛利→費用→逐項業外敏感度→稅／歸母→股數→PE推估，不再以舊EPS相減、前一年EPS天花板或人工EPS／目標價覆寫。
- 全年季節性基準加當期差異，係數只在前年度資料訓練。依產業至少50筆訓練樣本選係數，其餘用全體係數。2026H1保留期不參與擬合。
- 同股數基礎算EPS；已發行普通股加全額CB與已披露加權稀釋股數取較高者，避免重複加稀釋。外幣CB缺匯率／條件阻擋點估值，未確認後續轉換價不得正式通過。
- 依公司歷史及同產業PE分位數推導，排除自己；目前同業尚未逐家完成業務匹配，研究值不等於已核准合理PE。
- 工程／交屋須認列及訂單推導，通路須單位價差／庫存周期，地產開發須資產價值推導。缺資料只保留診斷值、不進主要排名；極端>150%估值另待查，不改動成較小的EPS。
- 負OCF是應收／存貨／應付及資金周期覆核觸發，不固定扣分或自動Exit。實際PPE及另外報導設備預付款分列；舊現金減全額CB賣回只能稱靜態敏感度。
- 13項品質證據逐項評估，缺資料與有證據的失敗分開。來源須有身份、期別、原始hash、可得時間、核對時間及期限。預測簽核綁定完整程式hash、目標日與價格日。
- 年季由資料讀入；跨年無完整年度財報時，使用已公告12月累計營收並明標未審，缺此基準留待補。資料取用時間不得晚於估計形成時間。
- 模型錯誤按公司隔離；來源失敗保留有舊日期的最後可用來源。關鍵hash不符則停止發布本次結果，保留上次輸出。

## 驗證與界限

37項單元／整合測試通過。66家當期原始數字與另取官方彙總資料396個核心數值一致。八季主要欄位及現金總額勾稽，不等於完整四表與所有附註簽核。

1978家標準化財報、1980個有效報價。可比較研究榜單限既有66家原始當期核對群中的48家，其餘官方當期彙總加未驗歷史數值另列廣域研究，不冒充全市場正式TOP10；金融需另建ROE/PB模型。

會計訓練1785家、保留1783家，保留期營收中位絕對誤差7.62%（同期不變基準12.82%），WAPE18.93%（26.28%）。毛利率、費用率誤差分別1.48、1.02百分點。這些不是股價預測準確率或投資報酬。仍缺完整公告／修訂PIT、當時上市下市母體及歷史估計版本，所以投資回測績效留空。

真實正式A+/A++目前0/0；測試中完整合成證據可以產生A+，不計為真實股票。未知股息留空；Bear/Base/Bull未校準機率，不計加權預期總報酬，不下單或自動Exit。

## 新增公司證據

`tw-market-data/evidence/v880/certificates/代碼.json` 是 `{code,gates:{門檻:證據}}`；每個PASS／FAIL均須真實來源、方法、issuer、financial_period、available_at、checked_at、expires_at。核閱保留範圍另須重要性簽核；股數簽核需一致分母與CB現行條件。不能以合成資料或自行填PASS取代查核。

專用營運輸入放 `issuer_bridges/代碼.json`，包含同公司同財報期及目標日、建立與到期時間、來源URL/hash/可得日，以及三情境segments、業外、稅率、歸母比例和PE或NAV方法。函式只接受產能／利用率／單價／成本／剩餘待認列合約等營運輸入，不接受目標EPS或股價。

首次重建證據可用 `python scripts/build_v880_evidence.py --audit-workspace <已凍結原始證據資料夾>`。該轉接器僅對2026Q2種子；日後新增原始公司財報須核對身份、單位及期別再納入。不得重試或繞過受保護的MOPS歷史端點。
