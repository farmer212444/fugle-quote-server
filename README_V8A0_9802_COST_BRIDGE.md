承接V8.9.9「新廠爬坡 vs 結構性毛利衰退」全市場稽核。先前只能比較合併毛利率、不能歸因；鈺齊2026/9/17 **原公司法說簡報其實提供兩季細部銷貨成本**，因此可對已公開的材料、人工、製造費用的營收比率進行會計貢獻拆解。**不代表產能利用率、廠別工資、固定折舊或產品售價已被獨立辨識。**

公司精確的2025Q2 GM＝18.49%、2026Q2 GM＝13.94%，合計跌**4.55pp**；不應因整數百萬元的算術差異認定財報錯誤。

**最重要的修正**：材料和人工合計增加約**5.25pp**營收負擔，是公司公布的合併帳面主要毛利拖累；製造費用負擔反而改善、約抵銷**0.67pp**。這不代表新廠與毛利無關：新員工訓練、低良率及產線熟練度都可能反映在**直接人工**；且「製造費用」分類包括固定及變動項目，不能將其下降直接等同固定折舊下降。

另一個防錯：9/17簡報「各國產能變化圖」採用**新台幣億元的生產產值比例**，越南2026年1–8月65.9%等為生產產出分配，不是利用率；不得套入V8.9.9原本固定成本吸收因果公式。

## 後續判斷9802是否能上調2027 Base

優先查明：（1）新廠直接人工成本中的**訓練期低良率** vs **經常性工資**；（2）材料占營收增幅是否因用料變動、售價/客戶組合、匯率或採購成本；（3）各新廠的有效產能、實際利用率、每雙鞋ASP及良品率；（4）是否能以2026Q3的**真正毛利／單位成本**觀察到回升（截至2026/10/21，Q3收入已公告，但不可將其視為毛利已公告）。

條件式毛利恢復至17%／18%可能讓2027估值上升，但**在證據不足前不得自動提高EPS、合理PE、Base價、A+，更不自動發送買入或Exit命令**。
