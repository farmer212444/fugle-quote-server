# 研究估值前的官方股價更新

2026/11/9下午的研究報告已重新產生，但參考股價仍是11/6。實查證交所OpenAPI仍回傳1151106，櫃買OpenAPI已到1151109且偶有HTTP 525；兩個市場按日期查詢的官方來源則可取得11/9收盤資料。排程尚未完成時，重跑研究程式不應只更新報告時間。

## 修正

- 每日股價工作流程與研究工作流程共用 `scripts/collect_official_prices.py`。研究流程在估值前補查兩市；主分支有其他寫入、需要重建時，也先重新核對股價。
- 沿用官方日期補抓：兩市必須同一完整交易日，拒絕未來資料、日期倒退、重複代號與混日資料。任一市場失敗即保留上一份完整輸入，停止這次研究發布。
- 原始回應與SHA收據在寫入價格前保存；價格與manifest以暫存檔置換，同日修正保存舊版。研究發布會把價格、原件與報告一起提交，避免報告依賴未保存的輸入。
- 過期提醒由16:00提前至既有擷取流程的14:20門檻。這只是應補查的時點，不代表已證實當天開市或個股可成交；既有已公告休市紀錄仍適用。
- 13:40僅診斷的排程、所有原有排程及主分支發布限制均保留，沒有新增排程。

測試涵蓋兩市更新不同步、來源失敗後改用官方日期查詢、第二市場失敗保留完整舊版、原件雜湊錯誤、同日更正、冪等擷取、早盤僅診斷、未來與倒退日期，以及14:20的時區邊界。合成測試資料不視為市場證據。

程式修正只更新價格取得與發布流程，不改獲利推導、本益比、產業假設、機率或正式A+門檻。另外以既有流程補查新進榜的6574、3305、8110季度資料；新增的華東Q3公告與原件另行保存，這類財報更新造成的EPS變動與價格更新分開對照。原件擷取時間不冒充歷史首次公開時間，收盤價不冒充可成交價格。完整月營收母體仍依原有manifest，9月不會被改標為10月；完整PIT、機率加權期望報酬與買進認證仍待驗證。
