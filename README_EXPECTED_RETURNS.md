## 期間、機率與期望值

報酬期間為參考收盤日至目標日期，目標休市時以**已完成官方交易日曆**上目標日前最後交易日結算；不是 2027 單一曆年績效。參考收盤價為假設入場價，扣手續費、最低費用、稅、價差與滑價，不宣稱已在已知收盤成交，也不取代次日進場回測。成本及部位資金在實驗登錄時固定。

每初始股的期末持有價值及股利分開保存，分割改股數、股利留現金，不重複納入還原股價。股利未查核留空，經完整公司行動審閱確認無配息才可用零。未知權利、下市、破產或其他未有結算規格的事件保持待補；整批缺一檔即不能計入，不能只留下贏家。

歷史樣本須**同經濟方法 SHA256、同產業及完全相同持有日數**。各樣本的「實際期末每初始股價值／當時 Base 價」及「實際股利／當時 Base 價」形成聯合殘差分布。現行 Base 價乘上殘差，得到同時包含股利與所有觀察尾部的分布。每個不重疊批次等權、批次內公司等權。

以現行 Bear／Base 及 Base／Bull 價的中點切出三個狀態，兩側開放延伸、邊界歸較高組。機率是經驗質量，報酬是狀態內條件平均，**不能直接將三個情境點價當條件平均**。零機率狀態的條件平均留空。

`E[R_net] = Σ p(state) × E[R_net | state]`。

未來股利可以由完整歷史聯合分布估計，必須標示為經驗估計，不能冒充已公告股利。此方法依賴同產業同方法殘差具有可比性的研究假設，不保證個別公司未來分布相同。

`annualized_expected_terminal_wealth = (1 + E[R_net])^(365.25 / days) - 1` 是期望期末財富的年化換算，並非年化報酬本身的期望。

## 時間外驗證

政策、成本、資金與程式方法雜湊先登錄，更改另立實驗。對每一批次，僅用發出時間前扣 5 天隔離後已到期且**首次實際驗證**完成的資料訓練。事後才取得的舊日期原件不能進較早訊號的訓練集。同日重跑或重疊持有窗不增加獨立期數。

固定研究政策最低為訓練 100 筆、12 個不重疊批次及 20 家公司；樣本外 100 筆、12 批次及 2 種市況。市況依訊號前官方加權報酬指數 63 交易日 ±3% 定義。這些是事前政策假設，不是準確度保證。

檢查多類別 Brier 對固定三狀態等權基準、五組可靠度落差不超過 10 個百分點，以及期望淨報酬絕對誤差不劣於明示「不含未知股利之 Base 價」基準。Brier 同時反映辨識力及校準，不能單獨當校準通過依據。全部檢查通過才列出**研究**期望值；正式投資超額報酬、OOS 和交易認證仍另行查驗。

以獨立完整批次重抽樣 2,000 次形成估計均值的 95% 區間，它不是未來股票報酬的預測區間。不對未見結果挑權重；將來如要比較多種方法或政策，須另立試驗及做試驗數校正，不得繼續在同一保留集上擇優。

## 仍待補的真實資料

## 歷史財報驗收接入

`historical_pit_readiness.py` 原來的驗收批次數是固定0，並沒有接入驗收結果。現在以 `evidence/v880/historical_pit_reviews/*.json` 的可驗證證據動態計數，沒有證據仍為0。

每個 `HISTORICAL_FINANCIAL_PIT_REVIEW_V1` 包必須綁定市場、季度、報表種類、歷史訊號、實際審查時間及 normalized_input 的路徑／SHA256。`issuer_reviews` 以具雜湊的逐家公司原件覆核文件完整涵蓋該批資料；缺一家公司、重複資料、後來修訂、雜湊衝突或缺公告版本證據均拒收。

逐家公司覆核文件限定 point_in_time 範圍，沿用既有原件SHA及具名來源身分審查要求，另外要求與 normalized_input 雜湊綁定、數值勾稽、訊號前修訂史、官方原始財報版本，以及另存的 `publication_and_revision_evidence`。事後可以審查歷史來源，但不得把今日審查時間／模型建立時間回填成當年已知。程式不代填人名、不自動簽發來源身分證明。

這只接通財報來源版本驗收；不等於當時上市下市母體、月營收、股數／CB、同業PE、完整公司行動與可成交性已通過，更不等於完整回測或機率校準已完成。歷史回放與年度校準的模型實作、來源補齊及獨立時間外驗證仍未完成，沒有將其改列為通過。測試中的人名、文件及PASS均明示為合成資料，不能用於正式資料或結果。
