# 製鞋研究與財報原件核對

V8.10.6 把來億兩筆具日期的轉換價修正與五家製鞋公司情境比較接入既有研究流程。

`python scripts/run_research_pipeline.py` 在主估值與股數檢查後執行 `scripts/footwear_review.py`，產出 `tw-market-data/rankings/latest_footwear_review.json` 與同名 Markdown。研究參數位於 `tw-market-data/config/footwear_research_v1.json`；每一個情境輸入都屬研究假設，尚未校準機率。

## 來億轉換價

TPEx `bond_ISSBD5_data` 的轉換價是發行條款欄位，不能當成最新重設價。保留原有在外本金來源，以 2026/6/26 公司公告轉載中的 2026/7/19 生效價更新 68901／68902，分別為 237.5／236.3 元。公告 HTML 原件壓縮封存，雜湊以解壓後位元組計算。

載入時重新解析發行人、債券序次、重設價格與生效日，檢查來源雜湊與取得時間。任何一筆不符會使該發行人的整組修改失效；較晚生效的已知條款不會被舊公告覆蓋。這次取得的資料不能回填為六月已可用的歷史樣本。

具日期公告可改善研究分母，但未證明其後再無調整。因此 `current_terms_verified` 與完全稀釋股數認證仍為 false；不授予任何品質門檻 PASS。

## 指定財報數字

`evidence/v880/footwear/originals.json` 保存來億、寶成 2026 Q2 合併財報的原件網址、SHA256 與取得時間。解析器檢查公司與財務期間後，核對指定當期欄位，沒有宣稱完成八季或全部附註認證。

來億使用 H1 欄而非第二季欄，並與既有官方鏡像的六項損益交叉核對。研究業外以 H1 指定附註移除匯兌、評價、處分項目，在全數轉換情境加回公司債利息後年化，仍屬情境假設。現金轉換與資本支出另行保留。

寶成按歸屬母公司之裕元權益、潤成投資帳面額與剩餘母公司權益施加研究折價；裕元已含寶勝，不另加一次零售持股價值。淨權益已包含負債影響，不再重扣合併負債。這不是已驗證市場 NAV，也不是 2027 年末帳面價值預測。

## 研究結果的適用範圍

五家公司的 Bear／Base／Bull EPS、PE 或帳面折價均可重算，但不覆寫主模型的 EPS、排名或 A+／A++。鈺齊的正式點估值封鎖保留，舊診斷 EPS 不顯示為可採用預測。新財務期、新營收月、混合價格日、原件不符或官方交叉核對失敗，都會使研究價格轉為待核。

價格空間是情境價格相對共同收盤日的變動，非年化或 2027 單年度總報酬；未確認未來配息與成本不冒充已知。未產生買賣指令，也未據此宣稱策略能打敗 0050。
