## 台塑化：EPS已恢復、PE假設更可疑

2026年前三季自結EPS **7.08元**，9個月直接年化 **9.44元**，與模型2027 EPS 9.14相近；故EPS 9.14**不是單就2026年化而言明顯離譜**。但是公司指出2026獲利受煉油價差、原油價格波動、購料／存貨利益影響，石化及烯烴仍有需求困難。不能把好景氣當成永久常態。

2027若EPS暫維持模型9.14：
- PE 8倍 → 約73元（相對106.5元，-31%）
- PE 10倍 → 約91元（-14%）
- PE 12倍 → 約110元（+3%）
- PE 14倍 → 約128元（+20%）
- PE 18倍 → 約164元（+54%，接近原模型）

上述8~18倍為**情境假設，不是經過歷史同業P/E驗證的合理區間**。正式調低原模型PE前，需要分辨持續性裂解利差、歷史循環分位數、資產負債表與2027常態EPS，不得因2026短期好報表直接認證18倍。

## 研究判斷（不等於正式買入指令）

- **名目模型潛在漲幅最高：鴻海**。但2027獲利高於2026H1簡單年化約74%，現金流橋接必須核對。

- **估值倍數最不穩定：台塑化**。2027 EPS可疑程度未必最高，但18倍PE未經景氣正常化驗證。
