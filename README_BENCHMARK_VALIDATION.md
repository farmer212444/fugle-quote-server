# 模型是否勝過大盤：V8.10.3驗證規格

目前尚無由完整行情、公司行動與成交審查支持的成熟比較期間。系統完成比較能力與事前登錄，不把程式測試結果當成投資績效。

既有 [Top30原件核對組合對0050](README_V8A8_TOP30_VS_0050.md) 的月度名單、下一開盤與1／3／6／12個月規格完整保留。
本文件新增的是**全研究Top30對加權含息指數的獨立診斷**，採下一交易日收盤與21日區間，不能混用兩組名單或結果。
兩組設計與既有模型競賽都計入試驗數校正；本次未宣稱0050原件與完整交易績效已備齊。

## 固定的比較方式

|項目|規則|
|---|---|
|研究選股|封存的研究Top30全部納入，每檔初始資金1/30；不依事後表現刪股|
|訊號時間|晚於模型估計、實際封存與實驗登錄時間|
|進場|訊號日後的第一個官方交易日收盤；與指數採同一時點|
|持有與換股|持有21個交易日報酬區間；前一組結束後才登錄下一組，不把每天重跑當成獨立樣本|
|基準|證交所發行量加權股價報酬指數（TAIEX TR），包含股息再投資，不扣指數交易成本|
|模型股利|稅前股息保留為現金或應收款，不再投入；個人所得稅未納入|
|模型成本|買賣手續費各0.1425%、每筆最低20元；賣出證交稅0.3%；單邊滑價0.1%與半邊價差0.05%|
|壓力情境|手續費、最低費用、滑價與價差加倍，證交稅不變|
|資金與交易限制|研究假設1,000萬元，成交參與率上限5%；碎股計算屬研究假設，非券商實際成交|
|現金空檔|模型未投資期間持有現金、利息設為0；大盤連續投資，計入這段機會成本|
|風險|以每日淨清算資產計算最大回撤，不能只看每期最後一天|

這是一個月度選股策略的驗證，不等於2027 EPS預測準確率，也不能替代「2024年底當時預測的2025年度前30名」回測。
手續費與稅率採明示研究基準；價差、滑價、成交參與率與資金並非經校準的最適值。每項假設在新實驗登錄時固定。

## 何時能說有足夠證據

先逐期呈現實際淨報酬、基準含息報酬、超額報酬、期間勝率與每日最大回撤。
是否有較穩定的證據，保留既有60個不重疊期間與至少2種市況的研究驗收門檻：

- 市況按訊號前63個交易日的指數報酬，事前固定為高於3%、低於-3%及中間三組。
- 每日相對財富的對數變動以21日循環移動區塊重抽樣，不把每日觀察當成獨立選股實驗。
- 10,000次重抽樣；依全部已登錄設計數校正信賴下限，不挑其中最好看的實驗報告。
- 基準情境與成本壓測的信賴下限都須大於0，連續期間淨報酬均高於大盤，模型最大回撤不得較大。
- 任何已成熟但缺失的期間、遭拒資料或來源錯誤都會阻擋「有足夠勝過大盤證據」。

以上為保守且明示的驗收政策，不是能保證未來獲利的統計結論。若只靠向前蒐集，60個21日區間約需5個交易年度，另有換股空檔。
第一期最早須待21個交易日報酬區間結束，而且行情、公司行動與成交審查齊全；單期贏過大盤只能算該期結果。
歷史重建與向前封存分開：今天補回的資料不能倒填成當時已登錄的預測，也不能拿2025結果調整規則再宣稱2025是未碰過的樣本外驗證。

## 防止回測失真

- 原始指數回應壓縮保存、保留首次擷取時間與雜湊，逐次重新解析；價格指數、錯誤月份、重複日期、改動的數值均拒收。
- 模型、成本或規則變更另立實驗；舊登錄與名單不可覆寫。同日重跑與未結束的持有期不增加獨立期間。
- 每檔交易行情須與永久保存的官方原件一致，完整30檔缺一不可。
- 股利、分割、現增、減資、下市與停牌等公司行動，以及漲跌停隊列與可成交性，需要各自來源及完整期間審查。
- 公司行動審查綁定實際採用的事件檔案，成交審查綁定行情檔案；僅新增一個`complete=true`不能產生有效績效。
- 不支援或缺資料的權利事件不以0替代，不刪掉未能成交的輸家。
- 已封存但跌出目前研究排名的公司仍留在兩市場的行情回補清單。

## 已接上既有排程

1. 研究排程抓取官方含息指數及登錄名單需要的歷史月份，來源阻擋時保留待補狀態。
2. 主分支估值完成並封存後，才登錄Top30比較名單。
3. 觀察階段重算有完整原件的結果，產生`tw-market-data/rankings/latest_benchmark_validation.json`與`.md`。
4. 上市與上櫃行情回補器使用未完成名單作為蒐集優先順序，不以新排名取代舊名單。
5. 財報既有排程每次額外各補2024、2025年底檢驗所需的最多2批資料；包含八季估值窗口之外的一季校準資料。

```bash
python scripts/benchmark_sources.py
```

新增歷史資料供校準及重建使用，估值仍只使用明示的八季窗口，避免補入較早資料就改變當期情境統計。
